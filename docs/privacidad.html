Política de privacidad

Esta información describe el complemento «Guías de Aprendizaje SENA» y este sitio estático, publicados por OSCAR E YANGUAS A para Colombia.

Cómo funciona el complemento

El paquete incluye instrucciones, catálogos, referencias, scripts y una plantilla. Esta versión no contiene un servidor del editor, cuentas propias, telemetría propia ni solicitudes de red desde sus scripts. Trabaja con los recursos y archivos que el entorno de ChatGPT o Codex le permite utilizar.

El complemento no transmite automáticamente tus documentos a este repositorio ni al editor. No se ha incorporado una base de datos del editor para almacenar conversaciones, archivos adjuntos o guías generadas.

Datos que aportas en ChatGPT

Los mensajes, archivos, resultados y ejecuciones se procesan en el entorno que utilices, según su configuración y las condiciones de OpenAI o del proveedor correspondiente. El editor no puede garantizar las políticas de conservación de esos servicios ni gestionar la eliminación de tus conversaciones.

Consulta la política de privacidad de OpenAI y los controles de tu cuenta. Evita introducir datos personales de aprendices que no sean necesarios para diseñar una guía.

Visitas a este sitio

Las páginas son archivos estáticos alojados en GitHub Pages. El código del sitio no añade formularios de recogida de datos, cookies de análisis, publicidad, rastreadores ni almacenamiento local. GitHub puede tratar información técnica de las visitas conforme a su declaración de privacidad.

Soporte público en GitHub

Si abres un Issue, tu nombre de usuario y el contenido que publiques serán visibles de acuerdo con la configuración pública del repositorio. El editor podrá leerlo y responder para atender la consulta. No publiques documentos personales o reservados. El contenido y su conservación dependen de GitHub y de las opciones de edición y gestión disponibles allí.

Consultas y eliminación

Para preguntas sobre el paquete o el contenido que hayas publicado en este repositorio, usa el canal de soporte sin incluir información sensible. Para gestionar datos de tu cuenta de ChatGPT o GitHub, utiliza las herramientas y canales del proveedor correspondiente. Este sitio no ofrece un formulario privado.

Cambios

La fecha de esta página identifica la versión de esta información. Si se incorpora un servidor, autenticación, formularios o analítica, deberán documentarse sus prácticas antes de ofrecer esas funciones.
