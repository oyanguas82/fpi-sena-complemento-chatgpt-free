Disponibilidad y alcance

Publicación en el directorio pendiente

Esta página presenta el complemento y sus condiciones de uso. La instalación pública se habilitará cuando se complete la revisión y publicación de OpenAI. No hay todavía un enlace de instalación pública verificado.

La generación de Word requiere que la sesión permita ejecutar Python y entregar archivos. El acceso desde una cuenta gratuita y sus límites dependen de ChatGPT; no se ha verificado todavía el flujo completo con una cuenta Free.

El complemento no incluye un servidor propio, claves de API ni conexión automática con SOFIA Plus. La revisión y aprobación institucional de los documentos corresponden al instructor.
