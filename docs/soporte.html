Soporte

El soporte del complemento se gestiona mediante los Issues del repositorio de OSCAR E YANGUAS A.

Abrir una consulta en GitHub ↗

Publicar una consulta requiere una cuenta de GitHub. Los Issues son públicos: no adjuntes nombres de aprendices, números de documento, calificaciones, contraseñas ni documentos institucionales reservados. Describe el error con datos ficticios y el mínimo fragmento necesario.

Qué incluir en tu consulta

  1. Versión del complemento y tarea solicitada.
  2. Programa y versión curricular utilizados.
  3. Mensaje de error y pasos para reproducirlo, sin información sensible.
  4. Si sucede al generar Word, indica si ChatGPT pudo ejecutar Python y adjuntar archivos.

Consultas frecuentes

¿Puedo usarlo con ChatGPT gratis?

El editor no cobra por el complemento. La disponibilidad del complemento, de Python y de las descargas depende de ChatGPT y de cada cuenta. La prueba completa en Free está pendiente y no se garantiza uso ilimitado.

¿Por qué aparecen campos pendientes?

El asistente no debe inventar información curricular ni datos del instructor. Aporta la fuente aplicable o revisa las propuestas señaladas.

¿Es un servicio oficial del SENA?

No. Es una herramienta independiente de apoyo para instructores.

¿El catálogo siempre está actualizado?

No se sincroniza automáticamente con SOFIA Plus. Comprueba el código, la versión y las advertencias contra el diseño curricular vigente para tu formación.

Otros servicios

Los problemas de cuenta, facturación, límites o disponibilidad general de ChatGPT se tramitan con el soporte de OpenAI. Este canal no puede modificar tu plan.

No se establece un plazo garantizado de respuesta para los Issues.
