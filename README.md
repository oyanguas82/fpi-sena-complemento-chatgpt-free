# Guías de Aprendizaje SENA · Complemento para ChatGPT

con 68 programas, 37 proyectos formativos e instrumentos de evaluación anexos.

Paquete convertido y validado localmente. La web está publicada; la publicación
del complemento en el directorio de OpenAI y la prueba completa con ChatGPT Free
están pendientes. Descargar el ZIP no equivale a instalarlo en ChatGPT.

El editor no cobra por el complemento. La generación de Word requiere que la
sesión permita ejecutar Python y entregar archivos. La disponibilidad y los
límites dependen de ChatGPT. No incluye servidor propio ni requiere claves API.

Las pruebas locales verificaron el paquete, el icono, las consultas al catálogo,
la generación Word desde la plantilla y el rechazo de criterios inventados y
horas inconsistentes. No acreditan revisión visual de una guía final ni
funcionamiento conversacional en Free.

Para publicarlo en ChatGPT, el editor debe completar identidad, comprobaciones,
declaraciones y revisión en el [portal de OpenAI](https://platform.openai.com/plugins).
[Instrucciones oficiales](https://developers.openai.com/plugins/deploy/submission).
Esta versión no incluye el módulo de planeación GFPI-F-134 en Excel.
